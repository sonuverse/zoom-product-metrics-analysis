# Zoom Product Metrics Analysis

## Project Overview
This project explores how product metrics can be used to understand user behaviour and product performance for Zoom, a video conferencing and collaboration platform.

The analysis uses the AARRR framework to identify key metrics across the user lifecycle and explain why each metric matters for product decision-making.

## Business Problem
The objective is to identify relevant metrics that Zoom should monitor across five stages of the user journey: Acquisition, Activation, Retention, Revenue, and Referral.

## Framework: AARRR

### 1. Acquisition
- Website Traffic
- App Downloads / Account Sign-ups
- Customer Acquisition Cost (CAC)
- Cost per Install (CPI)

### 2. Activation
- Account Setup Completion
- First Meeting Created
- First Meeting Joined
- First Collaboration Feature Used

### 3. Retention
- Daily Active Users (DAU)
- Monthly Active Users (MAU)
- Churn Rate
- Average Meetings per User

### 4. Revenue
- Free-to-Paid Conversion Rate
- Monthly Recurring Revenue (MRR)
- Average Revenue Per User (ARPU)
- Customer Lifetime Value (LTV)

### 5. Referral
- Net Promoter Score (NPS)
- Referral Invitations
- Referral Sign-up Rate
- Viral Coefficient

## Key Learning Outcomes
- Understanding the AARRR product metrics framework.
- Connecting product metrics to user acquisition, engagement, retention, monetisation, and referrals.
- Explaining how metrics can support product analytics and business decision-making.
